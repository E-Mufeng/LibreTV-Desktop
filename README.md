# LibreTV Desktop（非官方桌面整合版）

基于 [LibreSpark/LibreTV](https://github.com/LibreSpark/LibreTV) v2.21.1，保留 **AGPL-3.0-or-later**。
本仓库记录桌面整合与功能增量，不是 LibreSpark 官方桌面发行。

## 下载与使用

从本仓库 Releases 下载 `LibreTV-Desktop-1.3.1-win-x64.exe`，放入可写目录启动。
**1.3.1目前为预发布**：修复版源码、Web链路与打包已验证，新EXE的原生桌面启动/窗口验收尚未完成。
之前已发布的1.1.0保留，不覆盖旧成品。
Windows x64，无需另装 Node.js；当前成品未签名。默认本机访问密码 `123`。
仅监听 `127.0.0.1:28921`；会话签名密钥在本机首次运行随机生成。
配置、收藏、观看历史、下载和日志放在EXE旁 `LibreTV-data/`，不随本仓库和附件公开。

**新安装没有预置点播源。** 9路源是外置数据，不是EXE默认预置。
可在设置中导入独立的 `sources.public.json`（同样附于Release）；它只含公开接口，无账号、令牌、观看记录。
已有使用者可先导出自己的源列表，注意避免重复；不要覆盖自己的完整用户数据目录。

## 自1.1.0以来的增量

- **1.2.0**：个人片库（收藏待看、喜欢、看过、历史）、快捷键、本地JSON/Bilibili XML弹幕导入、观影记录备份能力。弹幕不连接在线公共服务。
- **1.3.0**：个人入口收进时钟抽屉及“···”，保留功能与原数据；新增吉吉源和Internet Archive适配，支持公开MP4搜索、选集、Range播放。MP4离线下载仍不支持，Archive不是海外新片/高清全库。
- **1.3.1**：修复视频代理整个响应流被8秒总时限截断的问题，改为响应头8秒、body读空闲30秒按块重置；保留鉴权、SSRF、Range和取消处理。
- 保留1.1.0的题材/地区/年代组合选片及热门推荐。9路公开接口可选导入，可用性会变化。

本次新增实现与原项目证据日期为 **2026-10-31**，不将上游累计代码算作当天新增。
既有证据：580项应用测试、4项桌面策略测试、lint/typecheck和生产构建通过；慢响应夹具从8.03秒中断修复为10.57秒完整传输。8个CMS源与Archive样本的Web接口/解码检查通过。
1.3.0有原生进程及桌面接口证据；1.3.1新EXE尚无原生启动验收，二者不混淆。
本次发布检查范围见 [PUBLICATION.md](PUBLICATION.md)，短时播放抽检不等于全库或长期稳定验证。
